# Recovery tool comparison — 17 October 2026

The target is the supplied Switch 1.1.0 NSO, Unity 2018.1.9f1, IL2CPP metadata 24.0, ARM64. The acceptance target remains buildable portable game logic. Metadata shells, comment-only native expressions, empty bodies and interop wrappers do not satisfy it. All experiments and caches remain on the verified USB; proprietary inputs were not submitted to a service.
