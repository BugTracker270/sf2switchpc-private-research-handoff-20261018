# AI tactic recovery

All 1,579 entries in the original tactics_compressed directory are accounted for: 1,578 bounded LZMA-alone decodes and one uncompressed XML reference. Size, EOF, trailing data and SHA-256 are recorded; the original compressed payloads remain intact.

Native TacticsArchiver readers now establish that the first uint32 is a **table type, not a format version**. Each archive contains multiple blocks. Paired-weapon archives have two zero-terminated identifiers per block; single-weapon archives have one. Each block then carries an explicit uint32 payload length. All 1,578 decoded archives contain 6,084 complete blocks: 2,985 movement tables (type 1), 2,985 attack-outcome tables (type 0), 57 dodge tables (type 2) and 57 shift collections (type 7). Empty weapon identifiers are genuine source values. Native weapon-order selection exists; a full Cartesian requirement is not inferred.

Version 1 of this research decoder incorrectly expected two names for both formats; 36 valid single-name records were consequently flagged as header errors, and one XML entry was misclassified. The authoritative version-2 manifest resolves these without altering any source assets. Its unresolved list is empty.

TacticalTableHolder.ReadAnimationNames (`0x1041D10`) reads a uint16 count, byte string-length array and corresponding ASCII names. ReadWeaponTypeList (`0x1041EF0`) reads an int16 count and the same name encoding. HierarchyNew (`0x1042000`) reads seven uint32 pool sizes, selected animation indices, a signed int16 distance multiplier and signed int16 distance values, int32 interframes, and interval-animation indices. Nested groups/tables/frames then partition these flattened pools. Every pool is consumed exactly and every payload ends at its declared boundary.

The complete validation accounts for 54,643 animation/group bindings, 107,430 tactical tables, 6,920,040 frame entries, 11,605,186 animation intervals, 64,799,755 distance boundaries and 53,194,569 interframes. All distance lists are nondecreasing. Shift collections contain 531 animations and 737,928 finite float values with validated node/frame dimensions. The authoritative catalog is `analysis/assets/ai-tables-v1`; original decoded bytes remain in `analysis/assets/tactics-decoded-v2`.

IntervalNew.IsDistanceWithin (`0x103E5A0`) uses inclusive lower and exclusive upper distance bounds. GetInterframeByDistance (`0x103E660`) selects the first segment with an upper boundary greater than the distance and returns -1 outside the range. Intervals.AddAnimationFromDistance (`0x103E830`) appends only candidates with a strictly positive interframe, preserving order. TacticalTable frame lookup uses frameIndex minus FirstFrameIndex; out-of-range lookup returns null rather than clamping to an endpoint.

The private C# reference evaluator at `analysis/reconstruction/ai-reference` compiles and passes 347,238 boundary checks across 22,811 original intervals in the unarmed matchup. `reports/native-ai-execution.json` records a separate bounded execution of the original ARM64 accessors, interval lookup, candidate filtering and frame-index logic, together with the original list helper functions. Native text remains read-only, metadata-initialization guards are pre-set and no game functions are mocked. This is function-level evidence; it is not execution of the complete Switch game or proof of AI decision parity.

Two tool errors were corrected: Cpp2IL's newer vtable offset shifted legacy virtual calls by one slot; Dumper's stock v24.0 runtime header also misplaced class/array fields for this build. The corrected runtime type archive gates static_fields at 0xB8, vtable at 0x128 and array elements at 0x20. Earlier typed exports are superseded by `analysis/nso/typed-behavior-ai-layout-v2`.

Remaining AI work includes caller policy, difficulty factors, reaction delays, tactic weights, animation-name resolution and runtime reachability. No inferred table value is substituted for source data. The runnable decoder is `src/re/tools/decode_ai_tables.py`; schema error tests are in `tests/test_ai_tables.py`.
